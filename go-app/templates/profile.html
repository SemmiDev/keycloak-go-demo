// Darimana data profil ini berasal?

Semua data di atas bukan diambil dari database aplikasi kita — data ini berasal langsung dari JWT ID Token yang diterbitkan oleh Keycloak setelah user berhasil login.

ID Token berbentuk JWT (JSON Web Token) yang berisi "claims" — pasangan key-value tentang identitas user. Field seperti sub, email, name, dan preferred_username adalah standard OIDC claims. Sementara realm_access.roles adalah Keycloak-specific claim.

Kita mem-parse dan memverifikasi token ini di handlers/auth.go pada fungsi Callback, lalu menyimpannya di server-side session. Halaman ini hanya membaca dari session tersebut.
