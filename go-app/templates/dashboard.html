Penjelasan: Kenapa route ini aman?
Route /dashboard dibungkus oleh AuthMiddleware di main.go. Middleware ini mengecek apakah session cookie berisi flag authenticated = true sebelum mengizinkan akses. Jika tidak ada, user langsung di-redirect ke /login. Flag ini hanya di-set setelah ID Token berhasil diverifikasi di callback handler.
Alur Auth Log
User klik Login, Go app generate state + PKCE verifier
Step 1
Browser di-redirect ke halaman login Keycloak
Step 2
User masukkan credentials di Keycloak
Step 3
Keycloak kirim authorization code ke /callback
Step 4
Go app verifikasi state, tukar code + PKCE verifier
Step 5
Keycloak return Access Token + ID Token
Step 6
ID Token diverifikasi signature-nya, claims disimpan di session
Step 7
✓ Kamu sekarang ada di sini!
